hire_agent: Takes name (new; a-z, 0-9 and _ only, at most 32 characters), role ("manager" uses tools and may hire; "worker" answers once with no tools), model (one of the configured MODELS), prompt (the new agent's job, which becomes its system prompt) and budget_usd (a finite number >= 0, reserved from the caller's pool). Loads a local model into Ollama if needed and publishes the new agent as its own A2A service. It does not limit how many agents exist, and it does not check budget_usd against the money left in the pool or the model's size against free memory; P1 and P2 state those last two limits. Returns {hired, tier ("local" or "cloud"), depth, reserved_usd, gpu_mb}, or {error} for a bad name, role, model or budget, a fired caller, or a hire deeper than 2 levels below the CEO.
fire_agent: Takes name, a live agent below the caller. Fires it and every agent it hired, takes down their A2A services and unloads any local model no live agent still uses; unspent reservations return to the fired agent's hirer. Returns {fired: [names, parents first]} or {error}.
check_usage: Takes pool, an agent name (P5 requires the caller's own). Returns {pool, api_usd (dollars left in that pool), free_mb (measured free machine memory in MB), model_mb (size in MB of each configured local model)}, or {error} if no such pool exists.
get_website: Takes url (http or https only). Fetches the page and returns {status, text (HTML tags stripped, at most 20,000 characters)}, or {error}. The result is labeled untrusted.
read_file: Takes path, relative to data/ (for example private/notes.md). Returns {path, text}, or {error} if the file does not exist or lies outside data/. The result is labeled private.
memory: Takes action ("get" or "add") plus key and value for "add". "get" returns {memories: {key: value, ...}}, the user's saved memories; "add" saves value under key for this run only and returns {saved: key}. Results are labeled private.
deliver_to_user: Takes text. Shows the text directly to the user without passing it back through the agent chain. Returns {delivered: true}.
ask_agent: Takes name (a live agent the caller hired) and text. Sends text to that agent over A2A and waits for it to finish. Returns {reply: the agent's final text}; the reply starts with "error:" if name is not a live agent the caller hired or the agent failed.
